Your own AI assistant. Asleep until you need it.

oc-workers runs your own OpenClaw assistant on your Cloudflare account. It sleeps when idle and wakes when you message it, so light use costs about $7 to $14 a month.

Get started Read the docs

What you get

Your account, your data
The Worker, the container and the R2 bucket are on your Cloudflare account. No service in between.
Wakes on a message
A Telegram message, a timer or opening the Control UI wakes it. The first reply after a sleep takes about 30 seconds.
Backed up while it runs
State copies to R2 as it changes, plus archives you can restore. A crash loses seconds, not days.
No AI key to start
The default model runs on Workers AI through your AI Gateway, with logs and spend limits.
Tools without keys in the box
Browser, web search, web fetch, speech and image tools run through your Worker. The container holds no credential.
One CLI
ochost installs, shows status, backs up, upgrades and removes the install.

Get started

You need Node 22.18 or later, Docker and a Cloudflare account on Workers Paid. Install takes 4 to 5 minutes.

  1. Install the CLI.

    npm install -g oc-workers

  2. Log in to Cloudflare.

    npx wrangler login

  3. Create the install. At the end it prints a login link to your Control UI.

    mkdir ~/my-oc && cd ~/my-oc
ochost init

Then connect Telegram: Quickstart.
